Install Arbitrage Radar

Arbitrage Radar is ready to install as an app on this device.

Android / Chrome: open Chrome's menu and choose Install app or Add to Home screen.

The app will launch full-screen and its core interface will work offline after the first load.

This copy is running as a local file. Android will let you test it, but Chrome cannot install a PWA until the folder is served from an HTTPS web address.

Use the included V2 deployment package on any HTTPS static host. Then open that address in Chrome and tap Install app.
